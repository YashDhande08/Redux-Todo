# 📝 Todo App (React + Redux Toolkit)

A simple and fully functional Todo application built using **React** and **Redux Toolkit**.  
Users can add, edit, delete and mark todos as completed.  
This project was created for learning state management with Redux in a real-world example.

---

## 🚀 Features

✅ Add new todos  
✅ Edit existing todos  
✅ Delete todos  
✅ Persistent state using Redux store  
✅ Clean and simple UI  

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React.js | UI development |
| Redux Toolkit | State management |
| JavaScript (ES6+) | Logic and components |
| Vite / CRA | Project setup (whichever you used) |
